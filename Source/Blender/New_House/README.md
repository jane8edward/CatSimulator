## 场景结构与性能

住宅按原设计重建外轮廓 10 × 9 m、层高 2.8 m 的两室一厅一卫、厨房与阳台。全屋使用 78 种本批 Tripo 资产与 1 种参考补建拖鞋，重复物品采用共享 Collection 实例；地板使用 16 个 Array 修改器。

高精度来源保留在原始 FBX 和导入检查副本。场景使用约 18 万面预算的资产副本，常规贴图以 1K、大件以 2K 进入场景；贴图已打包，便于单独打开工程。此文件仍是可编辑的视觉场景，未完成游戏运行时优化。

渲染采用 Cycles、Metal GPU、降噪和基础自然光/室内灯光。正式图为 64 采样，具体尺寸和耗时见每张图旁的 render.json。

## 仓库收录说明（2026-10-15）

本目录独立于旧 `CatHome90` 场景，当前作为 Blender 美术源工程收录，没有替换 Unity 的可玩关卡。原始 Tripo FBX 与贴图、79 个 Ready 资产、主场景、脚本、管理记录与最终渲染均已保留。

`*_Asset.blend` 属于可重建的高精度导入检查副本，未重复提交；需要再次修正时先执行 `06_脚本/audit_import.py`，从已收录 FBX 重建副本，再执行 `finalize_assets.py`。插件源码包 NH001、原始 ZIP、备份和试渲染中间帧仅保留本地。检查表中的 Asset.blend 说明指该可重建工作文件。

此目录位于 Unity 的 Assets 之外，无需 Unity .meta。协作者须先执行 `git lfs pull`；Unity 的既有资源和 .meta GUID 保持原样。
