## AI 3D 生成使用说明

1. 每次上传 `02_单物体图` 中的一张 PNG；宫格图用于对照与总览。
2. 以该图片主体的完整轮廓、材质和颜色为准生成单一模型，不生成白色背景、地面或投影。
3. 图片占幅独立调整，不代表实际物品大小。真实比例和单位参考对应资产 README / asset.json 及建模尺寸文件。
4. 套件提供可复用模块或变体：墙面平台为单模块；地毯、猫抓垫、毛巾、猫玩具保留形状变体；绿植连同原花盆展示，空花盆另有单图。

## 画面与检查

- 纯白背景、完整主体、没有环境遮挡和地面投影；保留用于识别体积的表面明暗。
- 家具移除独立摆件和猫咪；基础床垫、卧榻坐垫等主体组成保留，枕头、毯子等单列。
- Python 沿实际白色留白拆分，补齐方形白底。未重采样、未绘制或修改物件像素。
- 宫格实际尺寸为 1254×1254；单图尺寸记录在生成记录中。白底补齐不增加原始细节。
- 80 张单图已核对像素与原宫格一致，并通过边缘无截断检查。
- 猫砂柜修正为原图的两条通风槽和直线底座；绿植调整取景以保留垂枝；淋浴组件移除非原图底盘，按原图保留两片 L 形玻璃。
- 原图未展示的背面、内部和遮挡部分按同一构造补全，需在后续建模中核对。
- 本批为参考图交付；原有模型制作与引擎验收状态保留。
