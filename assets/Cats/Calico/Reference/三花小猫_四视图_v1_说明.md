# 三花小猫四视图 v1

依据提供的三视图参考生成，四张独立 PNG 均为 1536×1024 像素，白色背景，无文字标记，采用自然站姿。

- 前视图：猫咪正面对镜头。
- 左视图：观察猫咪自身左侧，猫头朝画面右边。
- 右视图：观察猫咪自身右侧，猫头朝画面左边。
- 后视图：猫咪背对镜头。

保留了圆脸、琥珀色眼睛、白胸白爪、棕色虎斑与橘色斑块、尾部深色环纹。原参考没有完整展示右侧，因此右侧局部花纹进行了合理补全。

建模载入时，以脚底接触线、耳尖和肩部高度调整各背景图的位置与比例。四张图通过共用参考保持外观接近，局部毛发轮廓和落脚高度仍存在少量差异；确定最终三维轮廓时需要结合各视图核对。

使用内置 imagegen 工具生成。完整提示词、参考来源、所选输出与文件校验值保存在 `三花小猫_四视图_v1_生成记录.json`。
