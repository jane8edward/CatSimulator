# 第二关家具与互动（本地开发）

当前开发版本号保留 0.3.3，本轮内容整理为本地 Git 提交，尚未推送或发布。修改前备份位于 `Source/Backups/before-house-tasks-20261018-230559`，包含住宅场景、关卡配置及全部已有脚本；此前新增的蓄力跳、机器人及软表面优化一并保留。

## 扫地机器人

- 机器人及停靠座保存于 `New_House_Preview.unity` 的 `NH_HouseTasks`，初始位置为客厅电视柜旁靠墙处，不再随猫咪动态生成或根据猫的位置寻找出生点。
- 银色圆盘直径约 36 厘米，主体厚 5.5 厘米。未载猫时可驶入主卧床底。轮廓、床垫和枕头支撑未替换。
- 猫咪直接跳上圆盘便能被带着移动，保持站姿，可以继续走动或跳离。F 只在车上切换坐下/站起；地面按 F 不会传送上车。坐着按空格会先站起，再按短跳/蓄力跳规则起跳。
- 保留自主分房巡扫、停止平移后原地转向、仅朝正前方行驶、遇障碍停止并绕行。站姿与坐姿乘客都计入通行空间，车上有猫时会避开低矮家具。

## 五项任务

靠近以下物体会出现黄色轮廓和 E 提示。五项均完成后显示结果，可以继续探索或重新开始。

| 位置 | 按 E 后的行为 | 保留的效果 |
| --- | --- | --- |
| 书房笔记本 | 靠近并咬屏幕右上角 | 实际裁掉角部网格，显示分支裂痕 |
| 玄关拖鞋 | 背对拖鞋蹲下撒尿 | 鞋面变暗并变湿，鞋内积液及地面尿渍扩散 |
| 客厅猫爬架 | 自动逐层攀爬 | 到达最高平台，复用第一关 `ClimbInteractable` |
| 主卧床头手机 | 咬断充电线 | 两段断线、露铜端头、瞬时火花，充电标识熄灭 |
| 客厅猫碗 | 低头吃猫粮 | 猫粮减少，可重复进食 |

仅替换主卧第二个床头柜的台灯；第一盏灯保留。手机有机身、屏幕、充电标识和接入墙面插座的充电器。原台灯在场景中停用，源模型保留。爬架顶层原有绿植移至电视柜空位，保留原模型和刚体，避免花盆阻挡落脚。

任务使用已有 `CatInteractable` / `LevelSession`，三个新交互动作叠加在各自骨骼上，未替换三只猫的模型、Avatar、走跑动画、跟随镜头或原有软表面效果。重开会恢复手机充电、完整电脑、干燥拖鞋、猫粮、机器人停放位置和任务进度。

## 构建与验证

普通构建继续使用 `CatSimulator.Editor.FirstPlayableBuilder.Build`，读取保存的场景。`HouseTasksIntegration.Prepare` 仅用于首次添加本轮家具，已存在时主动停止，避免重复生成。不要用旧住宅或第一关重建入口覆盖现有场景。

- `--check-house-tasks --verification-output <绝对目录>`：三只猫的直接跳上随车、F 姿态切换、跳离、E 提示、五项效果、复用攀爬、床底实际行驶和重开。
- `--check-jump-vacuum --verification-output <绝对目录>`：三只猫普通跳、蓄力跳、厨房水槽落地、坐姿随车、暂停；随后长时间八区域巡扫、朝前运动、原地转向、临时障碍与重开。加 `--jump-vacuum-quick` 可只做三猫部分。
- `--verify-game-flow`：两关菜单、三只猫独立骨骼与动画、第一关任务、第二关正常移动跳跃及重开。

本轮不重新宣称全场景 60 FPS；历史睡枕视角的性能边界仍见 `soft-surface-performance.md`。
