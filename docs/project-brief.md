# 猫咪模拟器：项目需求与决策

更新日期：2026-10-10（Asia/Shanghai）

## 核心关卡结构

用户已明确纠正：整体房子的布局固定，可活动场景随关卡变化；不同关卡开放不同活动范围。

- 共享一套住宅的空间布局，包括房间、墙体、门口与房间之间的连接关系。
- 每关配置活动范围，可为单个房间或多个相连区域。
- 每关设置固定天气、时间、角色安排、任务目标和场景初始状态。
- 猫可以在本关允许的范围内自由活动，按本关目标完成任务。
- 重新进入关卡后，破坏和物体状态恢复该关的初始配置。
- 首版只制作视频风格的小客厅。完整户型后续决定；确定后保持固定，按关卡配置活动范围。
- 主人的生活习惯用于设计具体关卡的情境与行为。

## 首关客厅：已确认玩法

- 玩家自由选择互动顺序。
- 通关条件为同时完成“打翻水杯”和“破坏窗帘”。每个必要目标独立记录完成状态。
- 猫爬架、纸箱和其他互动用于增添乐趣，属于可选互动。
- 猫爬架采用靠近后按交互键触发连续攀爬动作的方式。
- 首只青年猫的主外观参考 `assets/photo/b19b1392e76efc43ad0bff34a2c3d684.jpg`（猫窝里休息的猫）。其他照片用于补充角度和细节，体型保持视频的圆润方向。
- 重进关卡时恢复物体状态并清空本关目标完成状态。

## 当前技术决策

- 选择 Unity 6 稳定 LTS 版本与 Universal Render Pipeline（URP）。具体编辑器与包版本在初始化工程时固定。
- Blender 用于猫、家居、道具、材质源文件和动画制作。
- 先完成 Windows PC 可玩客厅样板，在本机检验画质与 60 FPS；设计资产、输入与交互系统时保留手机适配空间。PC 先行是当前实施顺序，手机端没有被移出最终平台目标。
- 每关提供明确任务目标，同时保留自由探索。
- 首关目标逻辑为水杯被打翻且窗帘被破坏；两项可任意顺序完成。可选互动独立于通关条件。
- 采用共享住宅环境与独立关卡配置：关卡定义活动范围、猫与主人等角色的初始状态、任务、道具状态、固定时间/天气与评分规则。进入或重玩关卡时应用该关配置。
- 首版制作一间小客厅并预留后续空间衔接；完整房屋布局确定后保持固定。
- 将“上猫爬架”和“拨倒水杯”列为首批重点动画与交互的参考样板；重点检查起步/起跳准备、身体重心、爪子接触位置、落地衔接、尾巴运动及拨动与物理反馈的配合。上述检查项为实施判断，不代表已完成制作或验收。
- 角色实现需要容纳后续多猫与双猫控制切换；切换期间未控制角色的行为、协作任务形式与解锁方式待继续澄清。
- 优先建立可玩的移动、镜头与交互流程，再持续提高猫、动画、光照和物理反馈品质；最终视觉基准仍为参考视频。
- 针对当前显存与跨平台要求，优先评估预计算室内间接光、可动对象的动态阴影、猫毛发分级及可控制成本的破坏效果。具体方案通过样板验证后确定。
- 引擎选择是工程判断，尚未证明参考画质与目标帧率已同时达成。

选择依据：URP 官方平台支持包含 Windows、Android、iOS；同一文档列出烘焙全局光照、混合光照、光照探针和反射探针等能力。这些支持与用户的小型室内、跨平台和本机性能目标相匹配。

## 当前工作阶段

首个 Windows 可玩原型 0.1 已生成：Unity 6.3 LTS + URP 工程位于 `Game`，自制 Blender 源文件位于 `Source/Blender`。客厅、第一只猫、基础骨骼和七组动作已导出；移动、镜头、两项必要任务、猫爬架与纸箱互动、命名、评分及重玩流程已实现。根据试玩反馈将猫缩小 25%，同步调整控制与镜头，并修正贴近墙壁时的观察角度。

0.1.1 根据试玩反馈修正自动视角转动导致移动方向反复改变的问题，补齐整个客厅实体部件的碰撞，扩大猫身体的碰撞检查，并重新摆放桌子和沙发。四处持续前进、家具阻挡、两种任务顺序与重玩均在实际渲染的 Windows 程序中验证通过；1920×1080 下的 8 秒环绕测试平均约 305–306 FPS，普通试玩设为 60 FPS。详细验证见 `docs/first-playable-validation.md` 和 `docs/camera-collision-fix.md`。

0.1.3 按用户选择接入 JonasDichelle 的 BlendSwap 猫和原作 Walk / run 动作；修正控制骨骼误参与蒙皮并保留八权重。用户随后反馈房间拥挤、猫稍大、毛发线条过多，已将客厅从 6.8×5.8 米扩大到 8.5×7.25 米，家具尺寸保持原样并拉开位置，猫比初次导入再小 10%，毛发缩短并清理异常长线条。两种通关顺序及碰撞、镜头验证通过，最终 1080p 短测平均约 189–232 FPS。当前游戏视频位于 `Source/Preview/first-playable.mp4`，动画展示位于 `Source/Preview/cat-animation-showcase.mp4`。转换与验证见 `docs/blendswap-cat-integration.md`。目标画质、完整住宅和手机端仍需后续开发。

当前资产为第一轮原型，尚未通过参考视频的视觉品质验收。接下来应按已确认优先级推进动作重心、脚掌接触与猫的外观，再打磨破坏反馈、环境和光照；完整住宅与手机适配仍属于后续阶段。
