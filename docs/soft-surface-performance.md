# 0.3.3 后续：软表面性能优化（本地，未发布）

## 改动

`SoftPillow` 缓存四脚水平落点对应的顶点影响权重。脚掌水平位置不变时，继续用原压力平滑计算下陷与回弹，但不再重复计算每个顶点的四次指数函数。压力与脚掌位置均不变时，跳过重复网格上传、法线计算和碰撞重建。垂直下陷不会改变水平影响权重。

保留 30 Hz 表面更新、15 Hz 碰撞同步、原下陷范围、脚掌影响半径、压力响应及恢复时间。场景、住宅模型、猫咪骨骼动画、镜头、灯光和画质设置均未修改。

修改前脚本备份：`Source/Backups/before-soft-cache-20261016-233410/SoftPillow.cs`。评测开始时 Git 工作区干净，基于 `32a1482`；评测当时未提交或上传。后续与蓄力跳、机器人及第二关互动一并整理为本地提交。

## 复测

Unity 6000.3.26f1 Windows 构建通过。RTX 3050 Laptop GPU、1920×1080、Direct3D 11，第二关验收测试上限 90 FPS。

| 视角 | 0.3.3 历史报告 | 本轮最终功能复测 |
| --- | ---: | ---: |
| 主卧床 | 43.8 FPS | 90.0 FPS |
| 主卧睡枕 | 53.6 FPS | 52.1 FPS |

历史数据来自 `Source/Verification/SecondLevel033`，并非本轮同环境交替对照。第一轮缓存实现曾测得睡枕 62.4 FPS，最终实现复测未稳定达标，不能据此宣称全场景达到 60 FPS。

最终第二关报告：`Source/Verification/SoftCacheFinal/upgrade-check.json`，54 项中仅睡枕性能项失败，保留 `passed=false`。三只猫移动跳跃、两关菜单、八区域路线、沙发跳跃、门窗、摆件支撑与有限质量接触、全部软表面下陷及恢复均通过。最终采样视角中位 72.7 FPS，5% 低帧率 59.7 FPS；短时采样不能代表全屋长期稳定性。

第一关卧室物理回归：`Source/Verification/SoftCacheBedroom/bedroom-physics.json`，`passed=true`。包括两只枕头变形、碰撞跟随及回弹，14 个物件、台灯倾倒、绿植落地、手机线约束、重开恢复，无运行错误。

## 定点诊断入口

现有 `--check-new-house-perf` 支持追加 `--profile-item MBR_NH048_SleepingPillow_01`，可在同一落脚点比较关闭软表面、暂停控制器、阴影及灯光参数等诊断状态；不传参数仍诊断原窗边软垫。这些开关仅用于测试进程，不保存场景或修改正常游戏画质。

定点报告位于 `Source/Verification/SoftCachePillowProfile/upgrade-check.json`。正常状态 90.0 FPS、关闭软表面 70.1 FPS、关闭太阳阴影 90.0 FPS，出现与简单单因素推断不一致的波动。该入口没有复现完整验收中的睡枕低帧状态，不能据此认定阴影或软表面是剩余瓶颈。诊断报告中的 `passed=true` 只表示诊断顺利完成，不代表全场景性能验收通过。下一步应复现完整验收相同的相机和场景历史，再采集逐帧 CPU/GPU 数据。
