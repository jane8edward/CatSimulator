# 0.1.1 视角与碰撞修正

用户反馈：多个位置触发自动视角切换，持续按 W 时猫反复转向；桌子与沙发重合；电视、电视柜及其他模型缺少碰撞，沙发靠背等部件会穿模。

## 实现

移动控制原先读取实际渲染镜头的朝向，镜头自动绕开障碍后改变了移动方向，角色新位置又触发下一次镜头绕行。现在移动参考玩家控制的 yaw，自动避障只影响画面。避障侧保持到视线持续畅通后再恢复，角度与距离恢复都有平滑过渡。

房间内实体网格采用逐部件 MeshCollider；沙发靠背、扶手、靠垫、电视、电视柜、桌腿、花盆、植物和猫爬架均有碰撞。静态家具不再使用未覆盖完整外形的旧家具代理盒。地板与墙体保留整体碰撞；木板共用地面阻挡。水体、高亮描边和停用的地毯纤维不作为实体。纸箱按各面碰撞，桌子按桌面、框架、桌腿碰撞，保留中间的可进入空间。

猫控制胶囊半径改为 0.14 米，并增加沿身体长度的胶囊扫掠与转身检查，覆盖头部和臀部。进入纸箱时沿箱子的长边站立，减少身体穿过箱壁。

Blender 中调整沙发、桌子及水杯、动作锚点位置，同步重新导出 FBX；按 Unity 中的实际模型包围范围核对，桌子与沙发间距为 0.715 米。修改前的源文件与场景已备份在 `Source/Backups/before-collision-fix-*`。

## 实际运行验证

两种任务顺序下均完成以下检查：

- 77 个实体网格的碰撞覆盖，缺失列表为空。
- 持续前进经过桌底、墙边、沙发旁和纸箱旁；位置没有沿输入方向反向，横向漂移低于 0.05 米。
- 桌底检查中自动镜头转向约 90°，猫保持直线前进约 1.61 米并钻出桌底。
- 角色接近沙发时，头部的身体范围停在沙发外。
- 对沙发靠背、扶手、底座、靠垫、电视柜、电视、花盆、桌腿、猫爬架柱和纸箱面执行真实 CharacterController 阻挡检查，并检查实际网格表面与碰撞穿透；全部通过。
- 水杯、窗帘任务任意顺序完成，两项缺一不能通关，重玩恢复状态；无运行时错误记录。

碰撞检查允许角色沿圆角或柱面滑动，使用实际网格表面、碰撞接触和穿透深度判定，避免将合法绕行误判为穿模。桌腿检查从侧面接近，避免检查初始位置落入桌框或地毯。
