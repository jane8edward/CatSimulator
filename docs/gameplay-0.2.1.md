# 0.2.1：住宅家具表面与通道修复

运行 `Builds/Windows/CatSimulator.exe`，选择第二关“90㎡住宅”。本次修改只在本地保存，未进行 Git 提交或上传。

## 修复内容

住宅的部分盒形网格面朝向内部，导致上表面从外面看不见，单面网格碰撞也会让猫从上面穿进去。修复前沙发坐垫外观顶部约为 0.4625 米，但向下的碰撞检测落到了内部约 0.2575 米处。

可玩住宅现在对封闭网格检查朝向，在单独的生成资源中纠正 523 个反向网格的三角面、法线和切线，并让显示与碰撞使用相同的修正网格。保留原有 UV、材质、加权平滑和各材质分组。18 块玻璃使用双向实体盒形碰撞，沙发坐垫下方增加连续承重层，跨坐垫接缝时保持支撑。桌子依旧分别保留桌面、桌腿的形状和下方空间。

调整了沙发、整套餐桌椅、猫窝、部分猫用品、书房椅子与脚凳、主卧衣柜和床头物品的位置。主卧门改为贴西墙打开；厨房两扇移门完全让出开口，阳台中间两扇移门向两侧收起，门框随停放位置调整。

原关卡 `LivingRoom.unity`、开始界面、两只猫的模型及动画源文件不替换。修改前的场景与代码备份位于 `Source/Backups/before-furniture-collision-20261015-145140`。

## 验证

`tools/verify-game-flow.ps1` 现在对两只猫分别执行实际跳上沙发、跨坐垫接缝、向靠背移动和走下沙发的回归检查，同时检查床垫、桌面、椅面和柜面顶部的碰撞。住宅通行路线进入主卧床侧及书房内部，并经过八个区域；同时验证开始界面、猫咪选择、第一关任务、跳跃和重玩。

编辑器 `Home90PhysicsValidation.Validate` 另外用有宽度和高度的体积扫过七个房间连接处，检查门口两侧的接近空间。通过检测的宽度为：客厅至走廊、走廊至玄关 0.70 米，主卧 0.65 米，书房和卫生间 0.60 米，厨房 0.90 米，阳台 1.20 米。这些数值是测试宽度，不是整个房间所有位置的最小通道宽度。

修复构建入口为 `CatSimulator.Editor.FullGameBuilder.RepairHomeAndBuild`，重新生成独立的可玩住宅并在门口净宽检查通过后构建。手工编辑可玩住宅后，使用普通构建；运行重新生成命令之前，备份希望保留的场景编辑。
