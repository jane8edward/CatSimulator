# 0.2.0：开始界面、两关与猫咪选择

运行 `Builds/Windows/CatSimulator.exe`。

- 开始界面只有“开始游戏”“查看猫咪模型”两个入口。
- 开始游戏后选择关卡。第一关保留客厅、卧室、打翻水杯和破坏窗帘的任务，猫爬架与纸箱仍是可选互动。
- 第二关是 90㎡住宅，暂时没有任务、通关提示或评分，可以在客餐厅、主卧、次卧与书房、走廊、玄关、卫生间、厨房和阳台探索。
- 猫咪页面支持拖动模型旋转、滚轮缩放、查看站姿或行走。点击“使用这只猫”保存选择，两关和重玩都会使用所选猫咪。
- 游戏里 WASD 移动，鼠标转镜头，滚轮调整距离，空格跳跃，Shift 奔跑。第一关用 E 互动。Esc 暂停；暂停菜单可返回开始界面。F4 打开内容菜单，Esc 可以继续当前游戏。

两只猫保留各自的 Avatar、骨骼、蒙皮与 Animator Controller，没有重定向到统一骨架。原版猫继续使用原有待机、行走、奔跑、跳跃和互动动画。阿比尼西亚猫使用自己的 38 骨骼行走片段，速度随实际位移匹配；尚未有原生跳跃、拍杯和抓挠片段，这些动作通过这只猫自身的姿态过渡适配，后续可以替换为新的独立动作。

90㎡住宅采用单独的 `Home90.unity` 场景。原客厅场景和原猫模型资源不替换。可玩住宅中打开了室内门和部分推拉门，在门洞处切开原来连续的踢脚线，并调整次卧椅子的位置，使通道可用。墙体、家具、地面及玻璃仍有碰撞。第二关暂时以移动、跳跃和探索为主，家具没有新增破坏任务。

## 构建与编辑

Unity 6000.3.26f1，Windows 使用 `tools/build.ps1`；Mac 使用 `tools/build-mac.sh`。构建包含开始界面、两个可玩关卡及历史美术预览；历史预览供编辑器和诊断使用，不出现在关卡选择页面。

`Game/Assets/Resources/Gameplay/CatCatalog.asset` 保存两只猫各自的模型、方向、比例和移动参数。普通构建直接使用保存的场景。编辑器菜单 `Cat Simulator/Create Full Game Entry And Home90` 会重新生成开始界面和可玩住宅；运行它之前保存并备份对这两个场景的手工编辑。

Windows 使用 `tools/verify-game-flow.ps1`，或命令行 `--verify-game-flow --verification-output <目录>` 验证开始界面、两只猫的选择、两关任务与自由探索、实际房间通行、跳跃、重玩和碰撞。现有 `tools/verify.ps1`、`tools/verify-bedroom.ps1`、`tools/verify-bedroom-physics.ps1` 继续验证原关卡。

2026-10-14 本机验收：两只猫分别完成第一关两项任务，并实际步行走遍第二关八个区域；跳跃、稳定转向、选择与重玩保持、碰撞检查通过，运行错误 0。RTX 3050 Laptop / 1080p 的住宅出生点两秒采样，原版猫平均约 152 FPS，新猫约 191 FPS；这不是全场景最差帧率或手机性能数据。原关卡两种任务顺序、卧室通行与镜头、动态物品、充电线和软枕头四项回归通过。菜单与新场景截图使用 Direct3D 11 离屏捕获，原关卡回归使用默认 Direct3D 12。结果与截图见 `Source/Verification/GameFlow`。
