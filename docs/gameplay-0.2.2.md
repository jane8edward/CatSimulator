# 0.2.2：镜头与移动重写、第二关猫咪尺寸

运行 `Builds/Windows/CatSimulator.exe`。

## 操作规则

- 鼠标控制镜头方向。W 沿画面朝向在地面上的投影前进，A/D 向画面左右移动，S 向画面后方移动；猫转向移动方向。
- 障碍物只能把镜头拉近，不会改变水平角度或俯仰角度。离开遮挡后，先等待短暂的持续空隙，再平滑恢复距离，避免桌边反复伸缩。
- 鼠标方向在移动前读取，实际画面与移动采用同一套朝向；跟随镜头不再通过滞后的目标点重新计算朝向。
- 滚轮手动调整远近，范围 0.65～3.2 米。空间极窄、镜头贴近猫身时临时隐藏猫身，防止模型填满画面；恢复距离后显示。此过程保持同一个方向，不切换镜头角度。
- 在狭窄处转身时，如果中间姿态被挡住而最终姿态可以容纳猫，直接采用可行的最终朝向。遇到真正无法转身的碰撞仍保持物理阻挡，移动方向继续由镜头控制。

## 第二关尺寸

第二关两只猫都使用原尺寸的 75%。模型、身体碰撞范围、脚部检测、控制器高度与宽度、台阶高度和镜头跟随点一并缩放。角色控制器高度从 0.36 米变为 0.27 米。

移动速度按体型同比缩放，以保持原来的步幅与动画节奏；跳跃高度保留，继续能够跳上现有家具。镜头默认跟随距离保持 2.05 米，让猫在画面中也相应缩小。

第一关与模型展示页保持原尺寸。两只猫继续使用各自的模型、骨骼与动画，未修改模型源文件。尺度由关卡配置的 `playerScale` 控制，切换关卡或重玩不会叠加缩放。

## 验证与构建

`tools/verify-game-flow.ps1` 对两只猫分别执行：

- 检查第一关尺寸为 1，第二关为 0.75，控制器和模型同步缩小。
- 在真实住宅茶几下持续按住 W，不在穿行过程中调整路线；逐帧比较实际镜头、移动及猫的朝向，并检查镜头碰撞。
- 保持 W 手动旋转视角，检查运动立即跟随新方向，以及镜头能恢复距离。
- 验证沙发跳上、接缝、靠背和跳下，以及八个区域通行、原关卡任务和重玩。

原关卡的回归现在要求镜头没有自动偏航，并通过物理查询检查镜头是否穿模，替代之前要求镜头自动绕转、保持大于 0.9 米距离的旧规则。

本次只需更新关卡尺度与代码，无需重新生成住宅。构建入口为 `CatSimulator.Editor.FullGameBuilder.UpdateControlsAndBuild`；普通 Windows 构建仍使用 `tools/build.ps1`。

修改前备份位置见 `.tools/controls-size/backup-path.txt`。验收报告与截图保存在 `Source/Verification/Controls022`。本次未暂存、提交或上传 Git。
