# 猫咪模拟器：参考素材观察与关卡结构

日期：2026-10-10（Asia/Shanghai）

已检查 `assets/video` 中 4 段视频与 `assets/photo` 中 5 张照片。新增视频逐秒抽取画面，另对原客厅视频的猫爬架和水杯动作检查了更密集的关键画面。以下描述基于可见画面，不推断视频的制作工具或实时运行性能。

## 用户明确的结构

住宅整体布局固定，活动范围按关卡变化。每关固定天气和时间，具有任务目标；重新进入关卡后恢复该关初始状态。首版仅做小客厅，完整户型后续考虑。

实施时把房屋布局作为共享环境，把活动范围、任务、角色、道具、时间/天气和初始状态作为关卡配置。可活动范围可以跨房间，不限定为一关只对应一个房间。

## 首版范围

- 一个视频风格的小客厅。
- 一只可命名的固定青年猫。
- 猫爬架、纸箱、桌子与水杯，以及与视频风格一致的必要家居。
- 重点完成移动、上猫爬架、拨倒水杯与窗帘互动。
- 玩家自由选择互动顺序。打翻水杯与破坏窗帘为通关必要条件，其他互动增添乐趣。
- 上猫爬架通过靠近后按交互键触发连续攀爬动作。
- 黄色物体高亮、任务提示与通关评分。
- 重进关卡恢复初始状态。
- 动画、猫外观和破坏效果优先，并同时满足既定的画质与 60 FPS 目标。

任务顺序、猫爬架操作与主参考照片已确认。失败/重试规则和后续双猫协作形式按开发阶段继续澄清，每次只询问少量必要问题。
