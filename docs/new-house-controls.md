# New_House 猫咪操控

在开始界面选择猫咪，然后进入“开始游戏 → New_House · 养猫之家”。新住宅现在使用项目已有的 `CatController`、`CatCamera`、`CatCatalog` 和动画驱动，默认进入第三人称自由探索。

|按键|操作|
|---|---|
|WASD|移动|
|鼠标|转动跟随镜头|
|Shift|奔跑|
|空格|跳跃|
|E|开关附近门窗|
|Esc|暂停、重开、返回开始界面|
|F4|共用内容菜单|
|V|全屋查看 / 返回猫咪操控|

全屋查看模式继续支持 1–4 切换预设视角，右键旋转、中键平移、滚轮缩放。进入查看模式会暂停猫咪并释放鼠标，返回时恢复跟随镜头。

## 场景接入

- 保留 New_House 的场景路径、菜单编号、现有家具布局和原始模型资源。
- 从现有可玩关卡复制玩家、相机、会话和 HUD 到新住宅场景，重连引用并使用独立的 `NewHouseLevel.asset`。
- 玩家比例沿用旧住宅的 0.75；猫咪外观、Avatar、动画和速度通过原有猫咪选择机制应用。
- 添加连续地面支撑及墙体、家具、窗户的静态碰撞。家具底部和门洞保持真实空隙。
- 卧室门在场景副本中拆为固定门框与打开的门扇，保留原网格三角面及材质；厨房、卫生间、阳台移门停放到打开位置。
- 镜头、猫咪目录及原有两个关卡未修改；共用控制器的猫爪查询兼容修正见互动说明。新住宅为自由探索；新增物理球与门窗互动见 [互动说明](new-house-interactions.md)。

本机演示入口：桌面“猫咪游戏/猫咪模拟器-场景选择版.app”。Unity 工程位于“猫咪游戏/CatSimulator-NewHouse-Selection/Game”。

## 已完成的实机检查

Apple M4 上，三只猫的四方向和斜向移动、奔跑、跳跃落地、骨骼动画、跟随镜头、墙体与家具阻挡、暂停、查看模式切换及重开均通过，运行错误为 0。

连续路线从实际出生点出发，通过同一控制器走到全部 8 个区域。已校正三处移门的下轨高度，并按世界单位设置窗框和玻璃碰撞厚度。家具底部及门洞保留通行空间；门扇和亚麻球现已使用独立的可运动碰撞体。

## 本地检查

`NewHouseGameplayIntegration.PrepareAndBuild` 只在新住宅中接入玩家和碰撞，再调用现有 Mac 构建流程。接入前的场景和演示程序保存在本机 `.tools/new-house-control-backup`、`Builds/Before-NewHouse-Control`。

使用 `--check-new-house-controls --verification-output <绝对路径>` 可检查三只猫的移动方向、奔跑、跳跃、动画、镜头、阻挡、暂停、查看模式和重开；连续房间路线使用同一控制器实际行走，不在路线中传送。结果、截图及路线记录位于 `Source/Verification/NewHouseControls`。
