# 住宅与阳台三花猫更新 0.3.0

## 第二关

- 房屋在两个水平方向各扩大 18%，占地约为原来的 1.39 倍。家具尺寸保持原样，桌柜与附属摆件一起重新定位；原有两关入口和住宅房间关系保留。
- 餐桌椅、长凳重新留出桌腿间隙；厨房冰箱正面朝向厨房内部；茶几上的摆件落在实际桌面上。
- 35 组小物件采用自由刚体和复合碰撞体，包括书、杯子、花盆、床头台灯、笔记本、球等。能够被猫推动、滚动、倾倒、从台面掉落。叶片等细薄部位采用花盆所在刚体的整体碰撞，避免细碎碰撞导致摆件自行弹飞。固定建筑、壁灯、地毯等保持固定。
- 27 个接触表面加入局部凹陷和回弹，包括沙发坐垫、床垫、枕头、床单被子、坐垫与软凳。四个脚掌附近的网格随接触平滑形变，碰撞网格同步更新；离开后恢复。床上各层同步变形，避免床单穿出被子。
- 柔软效果采用接触驱动的网格形变与碰撞更新；目前不包含整张被子的布料翻卷、枕头搬运或家具整体软体坍塌。

## 新角色：阳台三花猫

阳台的装饰猫保留原位；新增可玩角色另存，原版猫与阿比尼西亚猫的资源及动作控制器保留。

源 FBX 已有 50 根骨骼及基础蒙皮，本次完成权重整理、1 个无权重顶点的修复、比例校准、动作适配和 Unity 接入。源网格 25,515 顶点、51,882 三角形；Unity 因 UV 与法线边界拆分为 47,875 顶点。保留源外观、UV 与贴图。新版使用 4 个有效权重。

动作来自第一只猫的 `Cat_Game.blend`，包括 Idle、Walk、Run、Jump、Land、Paw、Scratch。通过休息姿态的世界旋转差适配到三花猫的体型，并用两节腿骨求解适配脚掌轨迹，修正落脚高度。新角色使用独立 Avatar、适配动作和控制器。

原动作的作者署名及来源沿用 [BlendSwap 猫接入说明](blendswap-cat-integration.md)。逐帧检查还包含腿部折叠和尾巴的地面约束，七组动作全部通过有限值与整体变形范围检查。

完整逐帧结果保存在 `balcony-deformation.json`：共 202 帧，网格保持有限值，没有整体拉爆，最低顶点始终在地面上方约 0.5 毫米或更高。静态休息姿态、原始输入和两个旧角色的资源保留。

- 可编辑源文件：`Source/Blender/BalconyCat/BalconyCat_Rigged.blend`
- 游戏资源：`Game/Assets/Art/BalconyCat`
- 可重复生成脚本：`Source/Blender/rig_balcony_cat.py`，以只读方式打开第一只猫的 `Cat_Game.blend` 后执行。

## 验证

`Source/Verification/HomeUpgrade030` 保存实机报告与截图。专项检查覆盖扩房、餐桌椅间隙、冰箱方向、摆件初始稳定性、茶几支撑高度、实际猫推球、书本移动、台灯倾倒、花盆掉落，以及沙发/床垫/枕头凹陷、碰撞和回弹。

书本的自由运动测试会临时将一本书放到空地，避免桌面其他物件阻挡结果；测试结束后恢复所有物件的原位。最终专项检查中，书本移动约 7.6 厘米，球被猫推动约 3 米，台灯倾斜约 38°。沙发、床垫约下陷 3.5 厘米，枕头约 4.5 厘米，碰撞同步且离开后恢复。

台面支撑检查从每件摆件的实际碰撞底面采样。轻微倾斜的书本或托盘，其世界轴对齐包围盒最低点不位于中心正下方；堆叠书籍的中心射线还可能先命中上面的书，误当作下方支撑。报告同时保留实际表面与旧中心射线的数值便于核对。第一关原有卧室物理、软枕头和手机充电线也已复测通过。

完整回归通过实际程序操作开始界面与三个选猫按钮，分别进入两关执行任务、探索八个区域、跳上沙发并穿过接缝、检查家具顶面和碰撞覆盖、持续按前进和手动转镜头、确认第二关缩放及重玩保留选猫。运行：

```powershell
./tools/build.ps1
./tools/verify-game-flow.ps1 -OutputFolder Source/Verification/HomeUpgrade030/FullFlow
```

2026-10-15 最终完整回归通过，运行错误为零；三只猫均走通八个区域，1,353 个场景网格的碰撞覆盖无缺项。RTX 3050 Laptop GPU、1920×1080 下，每只猫完成路线后各进行两秒取消限帧测试：原版猫 **114.88 FPS**、阿比尼西亚猫 **123.62 FPS**、阳台三花猫 **119.87 FPS**。第一关卧室物理回归也通过，短时测试平均 **141.86 FPS**。这些是当前原型的短时测量，普通游戏仍限制 60 FPS。

完整报告为 `FullFlow/game-flow.json`，汇总为 `summary.json`；`Builds/Windows/build-info.json` 记录本次程序版本、通过项和运行脚本 SHA-256。检查时应保留整个 `Builds/Windows` 目录，不能只拷贝 EXE。
