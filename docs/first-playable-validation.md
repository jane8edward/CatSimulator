# 可玩原型 0.1.1 验证

日期：2026-10-10。构建：Unity 6000.3.26f1、URP 17.3.0、Windows 64 位 Mono。构建成功，程序与数据约 106 MB，路径为 `Builds/Windows/CatSimulator.exe`。

保留猫的视觉缩放 0.75；本次修正自动镜头避障影响移动方向、家具重合与缺少碰撞的问题，详见 `camera-collision-fix.md`。

## 验证方法

使用 `tools/verify.ps1 -RecordPreview` 启动真实渲染的独立程序，分别按“先水杯后窗帘”和“先窗帘后水杯”执行。验证的交互调用与玩家按 E 时使用同一组协程；移动和跳跃走角色控制器的实际代码路径。测试在互动间使用位置跳转，因此没有覆盖玩家自行寻路的全部路线。

每次启动预热后，取消帧率限制及垂直同步，环绕镜头 8 秒，按逐帧时间计算平均帧率和 P95/P99 帧时间。普通试玩设为 60 FPS；演示录制在性能采样完成后进行，录制时设为 30 FPS。

设备：Ryzen 5 5600H、约 16 GB 内存、RTX 3050 Laptop GPU 4 GB。报告中记录分辨率为 1920×1080，并独立核对两次流程的截图，均为 1920×1080。

## 当前范围

本次验证证明当前小客厅原型的基本流程可运行，并在短时 1080p 测试中有较大的性能余量。尚未进行长期运行、热降频、完整住宅、手机端和最终视觉品质验证。

猫的网格、短毛表现和骨骼动作仍是第一轮资产；走跑和攀爬缺少充分的解剖、重心与爪子接触细节。水采用粒子与积水网格，窗帘采用受控动作与破损网格切换，室内间接光暂用环境光近似。以上仍需提高，参考视频的制作标准没有降低，也尚未达到。
